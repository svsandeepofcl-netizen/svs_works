# 🌿 Jungle Viper - Realistic Snake Game

An immersive snake game featuring realistic snake morphology, lush jungle environment, self-collision death mechanics, and a persistent **Top 5 Leaderboard**.

---

## 🎮 Game Features
1. **Size Growth**: Every tropical fruit consumed increases the viper's length and score.
2. **Jungle Environment**: High-detail Amazon rainforest backdrop with ambient floating fireflies and vines.
3. **Realistic Snake Anatomy**:
   - Emerald Tree Boa / Green Python gradient colors with dorsal scale spines.
   - Predatory amber eyes with vertical slit pupils.
   - Animated red forked tongue that periodically darts out.
   - Smooth continuous body segment connections and tapering tail.
4. **Fatal Self-Collision**: Biting any part of the snake's own body immediately ends the run.
5. **Top 5 Leaderboard**:
   - Records your best expeditions with medals (🥇, 🥈, 🥉).
   - Prompts for your Hunter Name when achieving a new top score.
6. **Synth Audio**: Dynamic crunch/chomp, crash, and high-score sounds powered by the Web Audio API (zero external sound files needed).

---

## 🕹️ Controls
- **▲ (Up)**: Move Up (`W`)
- **▼ (Down)**: Move Down (`S`)
- **◄ (Left)**: Move Left (`A`)
- **► (Right)**: Move Right (`D`)
- **Space / P**: Pause / Resume
- **R**: Restart
- **M**: Mute Sound
